# TIP - UNQ

Documentos LaTeX para el Trabajo de Inserción Profesional.

## Archivos

- `carta_presentacion_TIP.tex` — Carta de presentación
- `plan_trabajo_TIP.tex` — Plan de trabajo

## Requisitos

- MacTeX o cualquier distribución LaTeX con `pdflatex` instalado en `/Library/TeX/texbin/pdflatex`

## Generar PDFs

```bash
./build.sh
```

Los PDFs se generan en la carpeta `output/`.
